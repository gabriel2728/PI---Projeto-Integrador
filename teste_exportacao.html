🧪 Teste do Sistema de Exportação

1️⃣ Teste de Exportação de Simulação Nova

Clique nos botões abaixo para testar a exportação de uma simulação fictícia:

2️⃣ Verifica Se os Arquivos Foram Criados

  1. ✅ exportacao.php - Arquivo principal que gera os 3 formatos
  2. ✅ simulacao.php - Página de simulação com modal de exportação
  3. ✅ historico.php - Histórico com modal de exportação

3️⃣ Estrutura do Sistema

Simulação Nova (não salva):

  • Usuário preenche formulário
  • Clica em "Exportar"
  • Escolhe formato (PDF, CSV, XLSX)
  • Dados são enviados via POST para exportacao.php
  • Arquivo é gerado e baixado: Simulacao_YYYY-MM-DD_HH-MM-SS.{ext}

Simulação Salva (do histórico):

  • Dados são recuperados do banco
  • Usuário clica em "Exportar"
  • Escolhe formato (PDF, CSV, XLSX)
  • Dados são recuperados via GET com ID
  • Arquivo é gerado e baixado: Simulacao_{ID}_YYYY-MM-DD_HH-MM-SS.{ext}

4️⃣ Próximos Passos

  1. Teste em Simulação Página de Simulação:
    • Acesse simulacao.php quando logado
    • Preencha os campos de simulação
    • Clique em "Simular"
    • Clique em "Exportar" e escolha um formato
  2. Teste no Histórico:
    • Acesse historico.php
    • Clique em "Exportar" em qualquer simulação
    • Escolha um formato
  3. Verifique os arquivos baixados:
    • PDF deve ser legível em qualquer leitor PDF
    • CSV deve abrir em Excel ou Google Sheets
    • XLSX deve abrir em Excel

5️⃣ Arquivos Contêm

Todos os formato incluem:

Parâmetros de Entrada: - Vazão Mássica (m³/s) - Altura da Queda (m) - Potência da Turbina (MW) - Quantidade de Turbinas - Potência do Gerador (MW) - Eficiência do Sistema (%) - Horas de Operação/dia Resultados: - Geração Total (MW) - Geração Diária (MWh/dia) - Geração Mensal (MWh/mês) - Geração Anual (MWh/ano)
